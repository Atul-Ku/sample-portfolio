## ✨ Features of this Portfolio

* **Custom UI/UX:** Built entirely from scratch using pure HTML, CSS, and Vanilla JavaScript (No heavy frameworks used for the frontend shell).
* **Performance Optimized:** Lightweight assets, zero-dependency animations, and fast load times.
* **Modern Design:** Features a dark-themed UI with glassmorphism effects, custom CSS grid layouts, and a responsive mobile-first approach.
* **Interactive Elements:** Scroll-triggered fade-ins, animated performance metric counters, and dynamic navigation.
* **Cloud Hosted:** Configured for deployment on AWS S3 coupled with Amazon CloudFront.
